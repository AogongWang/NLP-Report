# TensorScope | NLP 原理实验室

一套**纯前端、可离线运行**的 NLP 原理仿真工具，用于《自然语言处理》课程作业。

它不是一个课程知识介绍站，也不是调用大模型 API 的聊天界面，而是一套可以**操作、计算、观察、比较、复现实验**的学习工具：算法真实计算，中间过程可逐项核对，所有实验结果透明、可复现。

## 六模块一览

| 编号 | 模块 | 内容 |
|---|---|---|
| M01 | 词向量 | CBOW / Skip-gram 负采样、GloVe 训练；相似度、类比、PCA 二维投影 |

## 快速开始：直接离线运行（无需安装）

项目根目录下的 **`release/`** 文件夹就是离线交付版：

```
release/
├── index.html        ← 双击它即可
├── app.js            （已打包，含全部算法与 D3）
└── assets/style.css
```

**双击 `release/index.html`**，用任意现代浏览器（Chrome / Edge 等）打开即可运行，**断网也能用**。

> 注意：双击的是 `release/index.html`（在 `release` 子文件夹里），**不是**根目录的 `index.html`——根目录那个是开发入口，需要开发服务器。

## 开发环境（重新构建/二次开发）

如需修改源码并重新构建，需要：

| 工具 | 版本要求 |
|---|---|
| Node.js | 20+（推荐 LTS） |
| pnpm | 8+（本项目用 pnpm 管理依赖） |

安装 Node.js 后，用 `corepack enable` 或 `npm i -g pnpm` 启用 pnpm。

**首次安装依赖：**

```bash
pnpm install
```

> 依赖会写入 `node_modules`；pnpm 的内容寻址 store 默认放在本项目 `.pnpm-store` 内（见 `.npmrc`/环境变量），避免污染全局。

## 六模块操作细节

所有模块入口在首页或顶部导航栏；每个模块左侧/中间为控件，右侧通常为「计算检查器」。

### M01 词向量

1. **语料**：文本框输入语料（一行一句；含空格按空格预分词，否则按字符切分）。
2. **算法**：选择 Skip-gram / CBOW / GloVe（选中项有绿色描边）。
3. **参数**：维度 dim、训练轮数 epochs、学习率 lr、随机种子 seed（窗口 window 默认 2）。
4. 点「**训练**」→ 上方显示**训练损失曲线**，下方显示 **PCA 二维投影散点图**。
5. **散点图交互**：拖拽平移、滚轮缩放（横纵轴同步跟随）、**Shift+拖拽框选**、点击点或名字选中。
6. **选中某点 / 搜索词** → 右侧「选中词原始向量」显示该词完整向量 + top-5 邻居。
7. **相似词查询**：输入词 → 显示相似词（点击结果可跳转定位到散点）。
8. **类比**：输入 A B C → 计算 A − B + C ≈ D（自动排除 A/B/C）。
9. 标签防重叠：离得近的点，名字自动隐藏重叠项，选中时始终显示。

### M02 序列模型

1. **模型**：选择 RNN / LSTM / GRU（绿色选中描边）。
2. **输入序列**：逗号分隔的 token id（如 `0, 1, 2, 1`）。
3. **参数**：随机种子 seed、Embedding 维度、隐藏状态维度。
4. **时间展开**：点击某一步查看该步状态（当前步高亮）。
5. **状态热力图**：行 = 隐状态维、列 = 时间步，与时间轴联动（当前步红色描边），发散色带（负→蓝/0→白/正→红）。
6. **反向传播梯度范数**：每个时间步的梯度范数柱状图（RNN 为解析 BPTT，LSTM/GRU 为数值梯度）。
7. **门值**：LSTM 显示 i/f/g/o，GRU 显示 r/z/n。
8. **步进控制**：前进一步 / 后退 / 重置。

### M03 Text-CNN

1. **输入文本**：字符级切分。
2. **Embedding 维度**：滑块调节词向量维度。
3. **词向量矩阵**：发散色带热力图（按序列排列）。
4. **卷积核参数**：两个卷积核（窗口 2、3）的权重可编辑；改后点「**重新计算**」更新。
5. **卷积滑动 / 池化动画**：点「播放卷积动画」→ 红框在**词向量矩阵的行上滑动**，最后停在池化最大窗口；可「停止」。
6. **拼接向量**：各卷积核池化值并排展示。
7. **分类层权重**：fcWeights 热力图 + 偏置。
8. **得分计算**：每类展开 `权重×池化值 + … + 偏置 = 分数 → softmax 概率`。
9. **点击某个卷积窗口** → 右侧检查器显示该窗口的逐项乘加与池化来源。

### M04 注意力机制

1. **打分方式**：点积 / 缩放点积 / 加性（实时更新）。
2. **目标 Query 向量** 与 **源 Key / Value 向量**（合并为一个编辑器，在中间区域），可改 token 名、数值，可**增删 token**。
3. **掩码**：在权重热力图上 **Shift+点击** 格子设置/取消掩码，被屏蔽格显示**红底 ×**；普通点击选中查看（选中格**绿色描边**）。
4. **权重热力图** + **加权输出 O = A·V** + 每行权重分布条。
5. **计算检查器**：点击权重格子 → 显示 权重 → 掩码 → 原始分数 → 输入的完整链条。
6. **A/B 对照**：设「基线 A」→ 改参数 → 设「对照 B」→ 显示配置差异与权重差值。
7. **导出实验 JSON** / **保存到记录**。

### M05 多模型对照

1. 点「**训练模型**」→ 用内置数据集（10 条训练 + 6 条测试，含否定/转折样例）训练 **NB / 线性 SVM / RNN / Text-CNN** 四个模型。
2. **评测指标**：测试集上的准确率、Macro-F1（NB 为对数概率、SVM 为决策分数（非概率）、RNN/CNN 为 softmax 概率）。
3. **批量样本对比**：全部样本 × 四模型，✓（绿）/ ✗（红，标预测值）。
4. **模型短板**：每个模型误分类样本，含**预测数据（各类概率/决策分数）+ 具体错误原因**。
5. **混淆矩阵**（朴素贝叶斯，测试集）。
6. **自主输入**：右侧输入一句话（**空格分词**，如 `虽然 画面 一般 但 故事 动人`）→ 四模型并排预测标签 + 置信度。

### M06 损失与优化

1. **验证案例预设**：慢收敛 / 正常收敛 / 震荡。
2. **参数**：学习率 lr、迭代数 epochs、**批大小 batchSize**、**随机种子 seed**、初始参数 [w0, w1]。
3. 点「**运行训练**」→ 上方**训练损失曲线**（每步真实评估），下方**二维损失等高线 + 优化轨迹**。
4. 点曲线上的点 → 检查器显示该步损失、参数、梯度范数。
5. 改参数后状态显示「结果已过期」，重新运行才更新。
6. **保存到记录**。

## 共享功能：数据集管理 & 实验记录

### 数据集管理（导航「数据集」）

- **内置示例**：情感二分类数据集。
- **文件导入**：TXT（一行一句）/ CSV（首行表头，自动识别 text/文本/内容 与 label/标签/类别 列）/ JSONL（每行 `{"text":…,"label":…}`）。
- **自动统计**：标签分布、长度分布（字符数）、重复检查、前 20 条预览、结构校验。

### 实验记录（导航「记录」）

- 在 **M04 / M06** 点「**保存到记录**」保存当前实验（模块、参数、结果）。
- 记录页可：查看配置/结果 JSON、删除、**导出全部**（下载 JSON）、**导入**、清空。
- 记录存于浏览器 `localStorage`（离线可用），导出得到 JSON 备份。

## 离线交付说明

- `vite.config.js` 使用 `base: './'` + **IIFE 打包** + 后处理去掉 `type="module"`/`crossorigin`，使 `release/index.html` 在 `file://` 下可直接打开。
- 不依赖任何 CDN、后端、动态 import、网络请求；数据在构建时打包或内置。
- 计算（训练/前向）在浏览器主线程或（未来的 Worker）中运行，全部为真实算法。

## 算法真实性声明

- 所有模块的数值均来自**真实计算**，不使用 `exp(-t)` 之类的伪造曲线。
- 随机初始化、采样、shuffle 均来自**可播种随机数生成器**（默认种子 42），同一参数可复现。
- 梯度：M02 的 RNN 用**解析 BPTT**、LSTM/GRU 用**数值梯度（有限差分）**；M06 的 Logistic 梯度经**独立有限差分校验**。
- 数值稳定性：softmax/log-sum-exp/sigmoid/交叉熵均为稳定实现；掩码整行屏蔽不产生 NaN。
- 各模块的简化假设（维度、窗口、分词方式等）在界面中有说明，不隐藏模型能力边界。

## 给他人运行 / 交付

**方式一（推荐，最省事）：直接发 `release/` 文件夹**
